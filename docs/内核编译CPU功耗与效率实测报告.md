## 三、功耗实测（RAPL）

RAPL 在 CPU 内部提供能量域，本次读取情况：

| 能量域 | 含义 | 结果 |
|---|---|---|
| package-0 | 整个 CPU 封装 | **平均 97.3 W / 峰值 112.1 W** |
| core | 全部 CPU 核心 | 平均 77.5 W |
| uncore（专用计数器） | 环形总线 / L3 / 内存控制器 | 本平台计数器未累加，改用 package − core = 19.8 W |

**功耗随时间变化（三段法）**：110.5 W -> 104.6 W -> 77.2 W

- **前段**（高峰期）：大量 .c 文件并行编译，16 线程全占满，稳定在 **110 W 上下**。
- **中段**：小幅回落（104.6 W），符合睿频随功耗预算与温度动态调整。
- **后段**（收尾）：目标减少、出现链接与单线程阶段，利用率下降，功耗降到 77 W。

**与官方规格对比**：i5-14400 的 PL1（长时功耗）= 65 W，PL2（短时睿频功耗）= 148 W。
本次编译平均 97.3 W、峰值 112 W，**高于 PL1 但远未触及 PL2**，属于持续中高负载，完全在 CPU 设计范围之内。

## 七、测量方法

在编译进行的**同时**并行运行三类采样器（均为 1 秒间隔）：

1. **功耗**：通过 pkexec 提权后读取 /sys/class/powercap/intel-rapl:0{,:0,:1}/energy_uj（微焦计数器），对时间差分得到瞬时瓦数，对时间积分得到总焦耳。已处理 32 位计数器回绕（本机 max_energy_range_uj = 262143328850 ≈ 72.8 Wh）。
2. **频率**：读取 16 个 cpufreq policy 的 scaling_cur_freq，按 P 核（policy0 - 11，上限 4.7 GHz）与 E 核（policy12 - 15，上限 3.5 GHz）分组求平均。
3. **温度**：coretemp 的 Package id 0 与全部 Core N 传感器。
4. **利用率**：/proc/stat 的 Δidle / Δtotal。

编译的起止时刻由脚本在 make 前后取 date +%s 记录，分析时严格按该区间裁剪积分。

## 九、误差与说明

- **RAPL 覆盖 67.4%**（219.6 秒 / 326 秒）：采样器取得 root 授权耗时约 106 秒，编译前段无功耗记录，报告中已按实测趋势（前段 110.5 W）外推，并给出 8.8 ~ 9.2 Wh 区间。
- RAPL 的 package-0 **只统计 CPU 封装**，不含主板 VRM 转换损耗、内存条、SSD、风扇等。整机插座功耗（墙插功率计读数）通常比该值再高 **20 ~ 40 W**，即整机约 **120 ~ 140 W**。
- uncore 专用计数器在本平台不累加（读数恒为 0），因此非核心功耗用 package − core 推算，属合理近似。
- 电费按 0.55 元/度估算，实际以当地电价为准。
